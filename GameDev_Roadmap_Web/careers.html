필요 성적

성적은 숫자보다 방향이 중요합니다

컴퓨터 관련 학과는 수학, 과학, 영어, 정보 과목의 기초가 중요합니다. 상위권 대학일수록 내신과 수능 모두 높은 수준을 요구하는 경우가 많고, 학생부종합전형에서는 프로젝트 기록과 탐구 활동의 깊이가 크게 작용합니다.

상위권 목표 수학 심화, 과학 탐구, 영어 독해, 알고리즘 문제 풀이를 꾸준히 기록합니다.
중상위권 목표 정보 과목 성취도, 교내 탐구, 동아리 프로젝트, GitHub 정리를 함께 준비합니다.
실무형 목표 전문대, 폴리텍, 부트캠프, 온라인 포트폴리오로 빠르게 결과물을 쌓습니다.

웹 서비스, 데이터 분석 보고서, 보안 실습 기록, 게임 프로토타입처럼 결과물이 보이는 활동을 만듭니다.

준비 로드맵

1년 계획 예시

  1. 1단계 기초 문법과 컴퓨팅 사고

    Python 또는 JavaScript 하나를 골라 변수, 조건문, 반복문, 함수, 배열을 익힙니다.

  2. 2단계 작은 프로젝트 3개

    계산기, 설문 결과 페이지, 간단한 게임처럼 완성 가능한 프로젝트를 배포합니다.

  3. 3단계 분야별 심화

    AI, 데이터, 보안, 게임, 웹, 클라우드 중 한 분야를 골라 강의와 실습을 묶습니다.

  4. 4단계 기록 정리

    프로젝트 목적, 사용 기술, 어려웠던 점, 개선한 점을 문서로 남깁니다.
